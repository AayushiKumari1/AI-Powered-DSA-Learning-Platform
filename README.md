# EduMentor — AI-Powered DSA Learning Platform

EduMentor combines DSA lessons, a coding workspace, proctored tests and an AI mentor in one place.
Learners study a topic, take an AI-generated quiz, solve problems in the browser, and get told what to study next.

**Stack:** React · Vite · TanStack Query · Tailwind CSS · Flask · SQLAlchemy · Socket.IO · Google Gemini · scikit-learn · Judge0 · TensorFlow.js

## Features

**Learners**
- **Topic lessons** with curated YouTube videos and time tracking per topic
- **AI quizzes** — 5 fresh Gemini-generated questions per topic; 3/5 to pass and earn XP
- **Coding workspace** — CodeMirror editor for Python, C++ and Java; code runs on Judge0 against hidden test cases
- **AI code analysis** — your time complexity vs the best known, an efficiency score and optimization tips
- **AI mentor** — routes each question to a mode (hint, code review, debugging, complexity, study plan) and gives hints in levels before full solutions
- **Proctored tests** — fullscreen, tab-switch and copy/paste detection, webcam face detection (TensorFlow.js BlazeFace) and microphone checks; 3 violations auto-submit
- **Topic mastery** — after a test, a scikit-learn model classifies each topic as Strong, Average or Weak and recommends the next one
- **Analytics** — XP breakdown, quiz pass rate, 30-day submission history, per-topic activity, CSV export
- **Community channels**, **mentor chat** (real time via Socket.IO), **flash notes**, **notifications**, XP and badges

**Admin console**
- Dashboard with platform activity, top learners and recent submissions
- Learner analytics with a per-learner profile (30-day activity, topics, practice, tests)
- Create and edit topics, problems (with a visual test-case editor) and tests; CSV import for topics and problems
- Announcements with read tracking, a mentor inbox, and community moderation

## Architecture

```
React SPA (frontend/)  ──JSON──▶  Flask REST API (app/routes/api.py, admin_api.py)
        │                                 │
        └──── Socket.IO (live chat) ──────┤
                                          ├── SQLite via SQLAlchemy
                                          ├── Google Gemini  (quizzes, mentor, code analysis)
                                          ├── Judge0         (code execution)
                                          ├── YouTube Data API (video lessons)
                                          └── scikit-learn model (topic mastery)
```

In production Flask serves the built React app at `/app`. In development Vite runs on :5173 and proxies
`/api` and `/socket.io` to Flask, so the session cookie is shared without any CORS setup.

## Getting started

**Requirements:** Python 3.10+, Node.js 18+

```bash
# 1. Backend
pip install -r requirements.txt
cp .env.example .env              # then add your GEMINI_API_KEY and YOUTUBE_API_KEY
python seed_demo_data.py          # creates instance/site.db with demo data

# 2. Frontend
cd frontend
npm install
npm run build                     # outputs frontend/dist, which Flask serves
cd ..

# 3. Run
python run.py                     # open http://127.0.0.1:5000
```

For frontend development, run `python run.py` in one terminal and `cd frontend && npm run dev` in another,
then open http://localhost:5173/app/.

### Legacy URLs
The React app is the **only** UI. The old Flask templates (`app/templates/`) and their CSS/JS (`app/static/`)
were removed because they duplicated it. `app/routes/legacy_redirects.py` keeps old links working:

* old page URLs (`/study/3`, `/coding/5`, `/admin/dashboard`, …) redirect to the matching React page
* old HTML form handlers (`POST /auth/login`, `/notes/create`, …) return **410 Gone** with the `/api/...`
  endpoint that replaced them
* the old `GET /admin/delete/<id>` links no longer delete anything (deletion is `DELETE /api/admin/...`)

The only non-`/api` endpoints React still calls are the original JSON ones: `/coding/run`, `/coding/submit`,
`/coding/delete_submission/<id>`, `/study/<id>/track-time`, `/coding-tests/submit-result`,
`/badges/equip/<id>`, `/badges/unequip` and `/chat/chatbot`.
